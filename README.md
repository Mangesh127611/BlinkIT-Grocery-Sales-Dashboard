# BlinkIT Grocery Sales Dashboard

Interactive **Power BI** dashboard analyzing BlinkIT grocery sales by outlet, product category, location and rating.

**Tools:** Power BI Desktop | Power Query | DAX | Data Modeling

---

## Business questions answered

- What is the total sales generated?
- Which outlet type contributes the highest sales?
- Which product categories perform best?
- How does outlet size affect sales?
- Which outlet location type generates the most revenue?
- How do sales trend by outlet establishment year?

## Dashboard preview

![BlinkIT Grocery Sales Dashboard](images/BlinkIT%20Grocery%20Sales%20Dashboard.png)

## KPIs

- Total Sales
- Average Sales
- Number of Items
- Average Rating
- Average Item Weight

## Features

**Slicers:** Outlet Location Type, Outlet Type, Outlet Size, Item Type, Item Fat Content

**Visuals:** Sales by Item Type, Sales by Outlet Type, Total Sales by Outlet Size, Sales by Outlet Location Type, Sales Trend by Outlet Establishment Year, Top Selling Item Identifiers

## Key insights

- Supermarket Type1 generates the highest sales among outlet types
- Tier 3 outlets contribute the largest share of total sales
- Medium-sized outlets generate the highest revenue
- Snack Foods is the top-performing product category
- Sales peaked for outlets established in 2018
- Average customer rating is 3.92, indicating generally positive satisfaction

## Dataset

Grocery sales data with: Item Identifier, Item Type, Item Fat Content, Item Weight, Item Visibility, Outlet Type, Outlet Size, Outlet Location Type, Outlet Establishment Year, Sales and Rating.
